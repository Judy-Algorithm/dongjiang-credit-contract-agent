# 东江信审与合同评审 Agent 典型案例

下面案例使用合成数据，金额单位均为人民币元。案例用于演示当前比赛原型的行为，不代表东江正式审批结论。每个案例都可以在本地新建案件后按步骤复现。

## 案例一：资料充分、合同正常，正常通过

### 业务背景

新客户申请 TKP 精密组件项目，月度订单额100万元，本次合同金额80万元，申请账期60天。客户资料比较完整，没有当前逾期，也没有既有授信占用。

### 输入字段

| 字段 | 示例值 |
| --- | --- |
| 客户名称 | 华南精密（合成）有限公司 |
| 客户类型 | 新客户 |
| 业务类型 | TKP |
| 项目名称 | 精密组件项目 |
| 月度订单额 | 1,000,000 |
| 合同金额/申请信用额度 | 800,000 |
| 申请账期 | 60天 |
| 资产负债率 | 45% |
| 净利率 | 10% |
| 流动比率 | 1.5 |
| 营收增长率 | 10% |
| 外部评级 | AA，展望稳定 |
| 当前未收款/在手订单 | 0 / 0 |
| 当前逾期 | 0天或留空 |

### 操作步骤

1. 在“发起信审”填写上述字段，上传一份评级报告或财务资料。
2. 确认提交，状态应为“等待信用审批”。
3. 信用人员点击“处理信用审批”，确认建议额度和账期后点击“批准”。
4. 状态变为“等待上传合同”，销售上传以下正文或合同文件：

   ```text
   甲方：东江集团；乙方：华南精密（合成）有限公司。
   合同标的：精密组件及技术要求。合同金额：800000元。
   付款及账期：月结60天。违约责任：赔偿直接损失。
   知识产权：背景知识产权归原权利人。保密：双方不得披露。
   解除与终止：违约催告后可解除。争议解决：适用中国法，深圳法院管辖。
   ```

5. 查看“合同结果”和“处理记录”。

### 预期结果和原因

- 信用建议为低风险时，TKP额度上限按月度订单额×3计算，即300万元；合同只申请80万元，没有超出额度。
- 60天没有超过低风险建议账期90天，也没有超过TKP Net 90天硬条件。
- 合同八类关键条款齐全，没有命中无责取消、间接损失等阻断模式。
- 最终状态：**已通过**。合同可进入后续系统回写或人工签署流程。

## 案例二：只有一项优质资料，必须补件

### 业务背景

新客户只提供月度订单额和 AAA 评级，没有财务数据、企业基础信息或历史合作资料。

### 输入字段

| 字段 | 示例值 |
| --- | --- |
| 客户名称 | 资料不足（合成）客户 |
| 客户类型/业务类型 | 新客户 / TKP |
| 项目名称 | 标准件项目 |
| 月度订单额 | 1,000,000 |
| 外部评级 | AAA |
| 其余财务、企业和合作字段 | 留空 |

### 操作步骤

1. 新建案件并提交，不必先上传合同。
2. 查看案件详情，状态应为“等待补充信用资料”。
3. 点击“补充信用资料”，上传财务报表、审计报告、注册信息或历史交易记录。
4. 资料重新解析后，回到信用审批页面；如果仍不足，可以继续补件或关闭申请。

### 预期结果和原因

- AAA 会提高外部评级维度得分，但不会替代其他维度。
- 当前建议模型要求最低资料覆盖率45%且至少有2个有效评分维度；本案只有一个维度，因此不能直接审批。
- 最终状态在补件后可能变为“等待信用审批”；若销售关闭，则为“已关闭”。

## 案例三：当前逾期31天，信用控制锁定后特别放行

### 业务背景

客户信用资料足够，模型建议额度300万元，但当前未收款最长逾期31天。

### 输入字段

| 字段 | 示例值 |
| --- | --- |
| 客户名称 | 逾期锁定（合成）客户 |
| 客户类型/业务类型 | 新客户 / TKP |
| 项目名称 | 续供项目 |
| 月度订单额 | 1,000,000 |
| 外部评级 | AA |
| 资产负债率/流动比率 | 45% / 1.5 |
| 当前未收款 | 0 |
| 在手已入单 | 0 |
| 当前未收款最长逾期 | 31天 |

### 操作步骤

1. 提交信用资料，信用人员点击“批准”。
2. 查看状态：应为“信用控制已锁定”，下一步为“处理特别放行”，合同上传按钮不可用。
3. 管理层打开特别放行页面，确认只放行本次订单或指定范围。
4. 上传 `市场总监批准.txt`、OA截图或批准邮件，填写意见后点击“批准”。没有附件时系统会拒绝提交。
5. 状态变为“等待上传合同”，再由销售上传合同。

### 预期结果和原因

- 系统规则是当前未收款逾期超过30天即锁定，不会因为模型分数高而绕过信用控制。
- 特别放行附件会记录 SHA-256、审批人和时间，并显示在案件详情的“审批证据”中。
- 如果管理层点击“驳回”，状态变为“特别放行已拒绝”，案件不能进入合同阶段。

## 案例四：合同命中无责任取消，退回销售修改

### 业务背景

信用审核已生效，合同金额和账期都在额度范围内，但合同写有“买方可随时取消订单且不承担任何责任”。

### 合同正文关键片段

```text
甲方：东江集团；乙方：合同风险（合成）客户。
合同标的：精密组件。合同金额：800000元。付款：月结60天。
违约责任：赔偿直接损失。知识产权：各自所有。保密：不得披露。
解除与终止：买方可随时取消订单且不承担任何责任。
争议解决：深圳法院。
```

### 操作步骤

1. 先完成信用审批并确认状态为“等待上传合同”。
2. 销售提交上述合同。
3. 在“合同结果”查看风险卡片，命中 `DJ-CANCEL-WITHOUT-LIABILITY`。
4. 状态为“等待修改合同”，销售修改为包含通知期、已采购物料补偿和合理减损机制的条款。
5. 点击“修改合同”并上传新版本，系统重新解析和审查。

### 预期结果和原因

- 该条款属于当前合同底线阻断项，不是可以直接通过管理层附件“覆盖”的普通特批项。
- 系统保留命中原文片段和修改建议，便于销售与客户协商。
- 新版本删除风险后，且其他关键条款完整，才可能变为“已通过”。

## 案例五：TKP账期120天，进入管理层特批

### 业务背景

客户信用已生效，合同要求 Net 120天，但合同没有无责取消或间接损失等硬底线条款。

### 操作步骤

1. 在信用阶段填写完整资料并批准授信。
2. 上传账期为120天、其他条款完整的 TKP 合同。
3. 系统命中 `TKP-SPECIAL-TERM`，状态变为“等待管理层审批”。
4. 市场总监/CEO 查看合同账期、终端项目背景和风险说明。
5. 若批准，上传终端项目统一账期或市场总监批准材料，再点击“批准”；若不批准，点击“驳回”。

### 预期结果和原因

- TKP一般条件不超过 Net 90天；120天超过硬条件，因此不能正常通过。
- 这是可授权例外，通常进入管理层特批，而不是直接退回合同修改。
- 特批通过后状态为“已特批通过”；附件会归档到案件证据目录。

## 案例六：TKM尾款50%，进入特批

### 业务背景

TKM项目合同约定走模后尾款50%，尾款期限90天。客户信用建议尾款比例40%以内，且一般条件不能超过40%。

### 操作步骤

1. 新建或选择业务类型为 `TKM` 的案件，完成信用审批。
2. 上传包含“尾款比例为50%，尾款90天内支付”的合同。
3. 系统命中 `TKM-SPECIAL-TAIL-RATIO`，状态为“等待管理层审批”。
4. 调整为尾款40%以内可直接重新提交；若必须保留50%，由市场总监/CEO上传比例批准材料后点击“批准”。

### 预期结果和原因

- TKM不仅看总金额和总账期，还看走模后尾款比例和尾款期限。
- 低风险建议上限为40%/180天；中、高风险的建议上限更低。超过一般40%比例会进入特别审批。
- 管理层批准只对明确范围、金额和有效期负责，不能理解为永久放宽全部 TKM 规则。

## 7. 案例复盘时看哪些地方

每个案例完成后，建议在案件详情依次检查：

1. **信用结果**：分数、风险等级、资料覆盖率、建议/正式额度和当前可用额度；
2. **信用控制**：是否锁定、锁定原因和占用计算；
3. **合同结果**：提取到的金额、账期、尾款条件和风险事项；
4. **处理记录**：资料读取、脱敏、审批、补件、特批和复核时间线；
5. **案件资料/审批证据**：文件名和已归档附件摘要。

答辩或内部演示时，推荐按“案例二补件 → 案例三特别放行 → 案例四合同阻断 → 案例五或六特批”的顺序展示，能够同时说明资料门禁、信用控制、合同底线和授权例外四种机制。
